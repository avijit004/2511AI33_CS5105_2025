🎯 About This Repository

This repository contains all coursework, coding assignments, and project work for the CS5105 / AI33 – Design & Analysis of Algorithms course at IIT Patna (2025).

The focus is on:

Writing clean, efficient algorithms

Analysing time/space complexity

Implementing DP patterns

Solving graph traversal & optimization problems

Building a real-world application using algorithmic design

🚀 Major Project: Seating Arrangement DAA (Streamlit + Docker)
<p align="center"> <img src="https://media.giphy.com/media/kaq6GnxDlJaBq/giphy.gif" width="300"> </p>
🔹 Features

Upload student + room CSV files

Auto-optimized seating allocation

Handles capacity, fairness, and randomization

Generates logs for transparency

Runs on local machine or Docker container

🔹 Tech Stack

🐍 Python

🎈 Streamlit

🧱 Pandas

🐳 Docker

🧠 Topics Covered
✔ Arrays

Searching, sorting, prefix sums, 2D arrays, optimizations.

✔ Dynamic Programming

Knapsack, LIS, DP on grids, MCM, DP patterns.

✔ Graphs

BFS, DFS, shortest paths, cycle detection, connectivity.

✔ Tutorials

Solutions for Tut-01 & Tut-02.

⚙️ Setup Instructions
🟦 Clone Repo
git clone https://github.com/avijit004/2511AI33_CS5105_2025.git
cd 2511AI33_CS5105_2025

🟩 Run Seating Arrangement App
cd Seating_Arrangement_DAA
pip install -r requirements.txt
streamlit run app.py

🐳 Run Using Docker (optional)
docker build -t seating-app .
docker run -p 8501:8501 seating-app
